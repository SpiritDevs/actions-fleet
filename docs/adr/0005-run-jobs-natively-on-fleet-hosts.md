# Run jobs natively on fleet hosts

Run workflow jobs directly on enrolled Macs and Linux machines using their installed toolchains. This is a personal/team build fleet, and the user chose straightforward local-style execution over managing disposable VMs. Workspaces and job credentials still need cleanup, but persistent machine state is accepted; maintainer approval remains required for outside contributions, and Shared mode offers best-effort moderation rather than VM-enforced resource isolation.
